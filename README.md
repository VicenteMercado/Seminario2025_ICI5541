Proyecto de Seminario de Título: GENERACIÓN DE MAPAS A PARTIR DE NARRACIONES LITERARIAS

1. relaciones_espaciales.py se encarga de la extracción de las relaciones espaciales  

2. solver_grafos.py se encarga de recibir estas relaciones extraidas y pasarlas por un solver  

3. comparar_oficial_vs_solution.py se encarga de comparar el grafo generado por el modelo y pasado por el solver con el grafo oficial 

EJECUTAR DE ESTA MANERA:
`python comparar_oficial_vs_solution.py official_graph.json solution.json`
